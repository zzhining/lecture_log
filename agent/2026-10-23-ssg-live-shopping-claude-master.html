RAG는 지식을 찾아오는 방식, 스킬은 일하는 방법을 꺼내 쓰는 방식

  • 파일 형식: 입력은 정리된 형식(md, csv, json), 출력은 용도에 맞게(html, svg, 파일)
  • 프로젝트는 자료와 규칙, 스킬은 절차를 고정. RAG는 자료를 검색하는 방식
  • 코워크는 작업 처리(비용과 권한 주의), 커넥터는 외부 연결(토큰, 누락, 인젝션 주의)
  • 아티팩트는 조작하는 결과물, 디자인은 시각 결과물(사용량과 관리자 활성화 확인)
INPUT입력
  • 정리된 파일
  • md, csv, json
TOOL도구
  • 반복 절차는 스킬
  • 반복 자료는 프로젝트
  • 여러 파일은 코워크
OUTPUT출력
  • 편집할 결과는 파일
  • 조작할 결과는 아티팩트
  • 보여줄 결과는 디자인
