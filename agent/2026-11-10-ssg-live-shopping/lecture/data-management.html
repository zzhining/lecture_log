오늘은 화면을 만드는 법이 아니라, 화면을 매주 살아 있게 만드는 데이터 이야기를 합니다. 두 개의 질문으로 시작해서, 두 번째 질문에 답하는 것으로 끝납니다.
QUESTION 1
이런 대시보드, 여러분의 업무에
도움이 될까요?
답을 바로 듣지 말고 손을 들게 해서 "도움이 된다 / 잘 모르겠다"로 나눠 봅니다. 이어서 3~5분 정도 대시보드를 직접 열어 시연합니다(한 줄 메시지 → 경고등 3가지 → 내 담당 보기). 시연이 끝나고 같은 질문을 다시 던집니다.
QUESTION 2
그렇다면, 이 대시보드를
매주 계속 쓰려면
데이터를 어떻게 관리해야 할까요?

한 번 만드는 것은 쉽습니다. 매주 같은 품질로 다시 나오게 하는 것이 진짜 과제입니다.

원칙 ③

달력도 데이터다

월을 걸치는 주차

40주차 = 9/28~9/30(9월) + 10/1~10/4(10월). 날짜마다 주차와 월을 따로 적어야 월 누계와 주차가 동시에 맞음

전년 같은 요일

26.10.05(월)의 비교 대상은 25.10.06(월). 날짜가 아니라 요일을 맞춰야 주말 효과가 섞이지 않음

연휴 표시

25년 41주차 = 추석. 달력에 표시해두면 대시보드가 "기저 왜곡" 경고를 자동으로 띄움

실제 사례: 41주차 전년비는 −13.8%였지만, 작년 41주차가 추석이었다는 것을 달력으로 확인하고 4주로 묶어 보니 +1.9%. "급감"이 아니라 "착시"였습니다.

달력표는 1년에 한 번, 연휴와 프로모션 시즌(블랙프라이데이 등)을 미리 넣어두면 됩니다.

  "우선순위": 1,
  "제목": "크림/젤 편성 회복",

  • 숫자는 숫자로, 글자는 "따옴표"로
  • 여러 명은 [ 목록 ]으로 → 이름을 누르면 내 액션만 골라낼 수 있음
JSON을 직접 타이핑할 필요는 없습니다. 엑셀에서 평소처럼 쓰고, 변환만 도구에 맡깁니다. 규칙은 하나만 기억하면 됩니다: 여러 값을 넣는 칸은 열 이름을 "~목록"으로 짓고 쉼표로 구분.
엑셀 → JSON 만드는 3가지 방법

MD는 ①번만 알면 충분합니다

① 권장 · 변환기 HTML
  1. 엑셀에서 평소처럼 작성 (첫 줄 = 열 이름)
  2. 엑셀_JSON_변환기.html 더블클릭 → 브라우저로 열림
  3. 엑셀 파일을 화면에 끌어놓기
  4. 점검 결과 확인 → ⬇ 전체 묶음 JSON

설치 없음 · 인터넷 연결 없이 동작 · 파일이 PC 밖으로 나가지 않음 · .xlsx와 .csv 모두 가능

② 생성형 AI에 요청

"첨부한 CSV를 JSON 배열로 바꿔줘. 첫 줄은 열 이름, 숫자는 숫자로, '~목록' 열은 쉼표로 나눠 배열로."

⚠ 실제 실적은 사내 보안 정책상 외부 AI에 올리지 말 것. 양식 테스트용 가상 데이터만

③ 데이터 담당자용 · Python 
import pandas as pd, json
시트 = pd.read_excel('샘플데이터_2026W41.xlsx', sheet_name=None)
묶음 = {이름: 표.astype(object).where(표.notna(), None).to_dict('records')
        for 이름, 표 in 시트.items() if 이름 != '안내'}
json.dump(묶음, open('전체묶음.json','w',encoding='utf-8'), ensure_ascii=False, indent=2)
매주 자동으로 돌려야 한다면 ③번으로 넘어가면 됩니다. 하지만 시작은 ①번으로 충분합니다. 엑셀에서 "CSV UTF-8"로 저장한 파일도 그대로 끌어놓을 수 있습니다.
