    변환 규칙 보기
      
 
    • 표 이름 = 시트 이름. CSV는 파일 이름에서 뒤쪽 기간 표시(_2026-10, _W41 등)를 뗀 이름
      • 
 
    • "안내" 시트, 이름이 "_"로 시작하는 시트는 건너뜀
      • 
 
    • 숫자만 있는 칸은 숫자로 바꿈(단, 0으로 시작하는 코드 예: 0012는 글자 유지). 빈칸은 null
      • 
 
    • 열 이름이 "목록"으로 끝나면 쉼표로 나눠 여러 값 목록([...])으로 바꿈. 예: "MD05, MD03" → ["MD05","MD03"]
      • 
 
    • 날짜는 2026-10-05 형식 글자로 입력 권장(엑셀 날짜 서식도 자동으로 바꿔줌)
      • 
 
    • CSV는 "CSV UTF-8" 저장을 권장. 일반 "CSV"(한글 깨짐 방식)도 자동으로 읽음
      •
