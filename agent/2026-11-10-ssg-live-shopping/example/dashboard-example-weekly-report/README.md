# 주간보고 작성·취합 시스템

설치가 필요 없는 HTML 파일 2개입니다. 라이브러리가 모두 파일 안에 들어 있어 **폐쇄망(오프라인)에서도 동작**합니다. Chrome과 Edge에서 사용하세요.

| 파일 | 사용자 | 역할 |
|---|---|---|
| `writer.html` | 담당자(MD) | 업무파일 업로드 → 1차 파싱 → 편집 → JSON 저장·제출 |
| `viewer.html` | 팀장·취합 담당 | 제출 폴더 로드 → 주차별·담당자별 보기 → PPTX/PDF 내보내기 |

## 1. 운영 흐름
1. **작성**: 작성기를 열고 팀·이름·담당을 입력합니다. 금주 시작일을 정하면 전주/금주 기간이 자동으로 정해집니다.
2. **업로드**: 한 주 동안의 업무파일을 끌어다 놓습니다. 지원 형식은 엑셀(.xlsx/.xls/.csv), 워드(.docx), 메일(.eml/.msg), 텍스트·HTML입니다. 메일 본문이나 메모는 붙여넣어도 됩니다.
3. **1차 파싱**
   - *규칙 기반*(기본값): 엑셀의 상품명·취급액·한계이익·달성률·방송일 열을 찾아 KPI와 상품카드를 계산합니다. 금주 날짜의 행은 '편성 계획'으로 분류합니다. 문장은 날짜·어미('예정', '완료' 등)·'지난주/이번주' 머리글로 전주와 금주를 나누고, 키워드에 따라 협력사·신상품·운영개선 등으로 묶은 뒤 개조식으로 바꿉니다.
   - *Claude API*(선택): API 키를 넣으면 LLM이 양식에 맞춰 JSON을 작성합니다. 폐쇄망에서는 사내 게이트웨이 주소를 엔드포인트에 입력하세요.
4. **편집**: 보고서 화면에서 글자를 클릭하면 바로 수정됩니다. 항목에 마우스를 올리면 추가·하위·이동·삭제 버튼이 나옵니다. Enter를 누르면 새 항목, Tab은 하위로, Shift+Tab은 상위로 이동합니다.
5. **제출**: `JSON 저장`을 누르면 `YYYY-MM-DD_팀_이름.json` 파일이 생깁니다. 이 파일을 공유 폴더에 넣으면 제출이 끝납니다.
6. **다음 주**: `전주 보고서로 이어쓰기`에서 지난주 JSON을 선택합니다. 지난주의 '금주 계획'이 이번 주 '전주 실적' 초안으로 들어오고, 각 항목의 `▶` 뒤에 결과를 적으면 됩니다.
7. **취합**: 취합뷰어에서 `폴더 열기`로 공유 폴더를 선택하면 하위 폴더까지 모두 읽습니다. 같은 주차·작성자의 파일이 여러 개면 가장 최근에 저장한 파일을 사용합니다.
   - 제출현황: 담당자 × 주차 표와 팀 추이 차트
   - 주차별: 팀 요약, 팀 통합본(전원 취합 1장), 개인별 보고서
   - 담당자별: 주간 추이와 주차별 보고서
   - `PPTX 내보내기`: 편집 가능한 도형과 차트로 만들며 4:3 또는 16:9를 고를 수 있습니다. 내용이 많으면 다음 장으로 이어집니다.
   - `PDF 내보내기`: 인쇄 창에서 'PDF로 저장'을 선택하고 용지는 A4 가로로 합니다.

## 2. 서식 표기 (편집 중 입력)
`**굵게**` · `==형광==` · `{up:증가(빨강)}` · `{dn:감소(파랑)}` · `{ac:강조}` · `{wn:경고}`
`→`, `※`, `①`로 시작하는 줄은 글머리 기호 없이 표시됩니다.

## 3. JSON 스키마 (weekly-report/v1)
```json
{
  "schema": "weekly-report/v1",
  "team": "푸드", "author": "서하은", "part": "김치",
  "weekStart": "2026-11-02",                       // 금주 월요일 (파일 식별 키)
  "prevRange": {"start": "2026-10-26", "end": "2026-11-01"},
  "currRange": {"start": "2026-11-02", "end": "2026-11-08"},
  "status": "submitted",                           // draft | submitted
  "updatedAt": "2026-11-02T12:02:00",
  "sources": [{"name": "방송실적.xlsx", "type": "xlsx"}],
  "metrics": {"편성비중": 3.3, "취급액": 5.29, "한계이익H": 36, "달성률": 117},  // 취합용 수치(저장 시 KPI에서 자동 계산)
  "prev": {                                        // 전주 실적 컬럼
    "kpiLabel": "실적현황\n(당초 比)",
    "kpis": [{"tab": "취급액", "value": "5.29억", "sub": "달성 117%", "kind": "num"},
             {"tab": "신상품", "value": "붉은대게김치 1kg", "kind": "txt"}],
    "panels": [
      {"tab": "주요상품현황 및 편성", "type": "cards",
       "cards": [{"title": "한채푸드 포기김치", "lines": ["한계 42백/H", "1.44억"]}]},
      {"tab": "주요 상품 실적", "type": "bullets",
       "items": [{"t": "김치_고효율 유지", "c": [{"t": "취급액 5.29억, 한계 36백/H", "c": []}]}]}
    ]
  },
  "curr": {                                        // 금주 계획 컬럼 (구조 동일)
    "kpiLabel": "운영계획\n(목표)", "kpis": [],
    "panels": [{"tab": "주요상품 현황 및 편성", "type": "tiers",
                "tiers": [{"label": "편성\n계획", "items": ["한채푸드 겉절이 : 11/8(일) 20시, 목표 35백/H"]}]}]
  },
  "note": ""
}
```
- 패널 타입은 `cards`(상품 카드), `bullets`(● / - / · 3단계 글머리), `tiers`(구분 라벨 + 목록) 세 가지입니다.
- 취합뷰어는 KPI의 `편성비중`, `취급액`, `한계이익`, `달성` 값을 숫자로 읽어 합계와 가중평균을 계산합니다. 취급액은 '억' 단위, 한계이익은 '백(백만원)/H' 단위로 적어 주세요.

## 4. 폴더 구성
- `submissions/`: 샘플 JSON 30개. 푸드 MD 5명 × 6주(9/28~11/8)이며 모두 가상 데이터입니다.
- `sample-files/`: 작성기 파싱 테스트용 파일입니다(엑셀 방송실적, 협력사 회신메일, 주간 메모). 11/9 주 보고 기준입니다.
- `내보내기_예시/`: 취합뷰어에서 내보낸 PPTX와 PDF 예시입니다.

## 5. 참고·제약
- PDF, HWP, PPTX 파일은 작성기에서 직접 읽지 못합니다. 내용을 복사해서 '텍스트 붙여넣기'에 넣어 주세요.
- 규칙 기반 파싱은 초안용입니다. 분류와 문장은 반드시 검토하세요. 엑셀 금액 열에 단위 표기(백만원, 억, 원)가 있으면 단위를 자동으로 바꾸고, 단위 표기가 없으면 백만원으로 간주합니다.
- 작성 중인 내용은 브라우저에 자동으로 임시 저장되지만, 제출은 꼭 JSON 저장으로 하세요.
